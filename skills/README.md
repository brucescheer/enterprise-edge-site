# Shared skills

## enterprise-edge-voice

Everything the three of us publish under The Enterprise Edge should sound
like one programme. This skill is how.

It encodes the narrative spine, the three edge names and their promises, the
programme facts, and the hard rules: no dashes, every statistic sourced,
nobody carries a case, and we never write about the commercial arrangement
between us.

Rule one inside it is that **getenterpriseedge.com is the source of truth**.
The skill tells whatever model is reading it to check the site before
drafting, which is what stops three people generating three brands.

**Claude Code or Claude Desktop:** copy `enterprise-edge-voice/` into your
skills directory.

**Claude Projects or ChatGPT Projects:** paste `SKILL.md` whole into the
project's custom instructions.

**One-off:** paste it at the top of the chat and say "follow this, and fetch
getenterpriseedge.com before drafting."

If the site changes, change `SKILL.md` in the same commit. A skill that
describes a site that has moved on is worse than no skill.
